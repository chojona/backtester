## Prespecified experiment, conditional on eligibility

**Minimum and periods.** Require one unchanged-register run of at least **120 consecutive eligible A/B sessions** with complete matched-support RV and no unresolved intervening weekday. Select the earliest qualifying run by first trading date; use its **first 120 sessions only** for the initial experiment, without searching forecast outcomes. Number those sessions 1–120. Sessions 1–22 are feature warm-up. Target sessions **23–72** form 50 training rows, **73–92** form 20 validation rows, and **93–120** form 28 untouched test rows. Record their actual calendar dates and a sample manifest before calculating model forecasts. If any RV measurement fails, break the run and reassess the 120-session gate rather than dropping a row and connecting across the gap. No current run qualifies; the 2026-07-07–09-04 run ends after session 44, so it has no preregistered training, validation, or test period.

**Daily target.** Primary estimator: full-session, unannualized **5-minute realized variance of raw selected-contract log returns**, `RV5(d) = Σ [log(P_end/P_start)]²`, on nonoverlapping 5-minute blocks anchored to each documented session/segment open. Use only completed one-minute bars in the retained selected contract, with positive prices and the versioned NQ trading-date grid. The first block starts from its first bar open; never include a previous session close, a contract-roll price jump, a maintenance break, or an unobserved gap. Retain the raw, unadjusted contract prices and report RV units and sampling count. No zero filling, interpolation, or annualization. The prior completed session's RV is the persistence forecast; HAR features are the 1-, 5-, and 22-session arithmetic means of this same RV5 series.

**Matched sampling check.** Prespecify 1-minute and 15-minute RV as sensitivity measurements, not alternate targets selected after results. Partition each session into complete, nonoverlapping 15-minute blocks, and calculate 1m, 5m, and 15m returns **over exactly the same union of 15-minute support**; require all constituent minutes for each block and full expected session coverage. Discard incomplete terminal tails at every frequency; record `samples` and `covered_minutes`. If a session's expected schedule makes the common support insufficient or any active minute lacks verified coverage, exclude the session and split the run. Apply identical session, segment, reset, and raw-contract rules to every frequency. Do not compare an RTH-only or truncated measurement with a full-session target.

**Information times.** A daily RV becomes usable only after the last required bar has completed and its availability timestamp has passed; the forecast origin for target session `t+1` is the completed feature session `t`. Training rows require `target_available_at <= origin as_of`. Fixed fits once on the 50 training rows. Expanding refits at each later origin using all then-available prior targets. Rolling refits using the **last 30 eligible prior targets**, exactly. Validation targets may enter later validation/test refits only after availability; test targets may enter later test refits under the same rule. Historical vendor revision/publication latency is not established by the OHLCV record, so this as-of convention is a retrospective information assumption, not evidence of live forecast availability.

**Benchmarks and scoring.** At each origin, persistence is the latest completed RV5. Historical mean is the arithmetic mean of the training targets available to that evaluation at that origin; fixed keeps its 50-row mean, expanding and rolling update with their eligible histories. Report MAE, RMSE, and OOS R² on identical ordered validation and test targets. For cross-evaluation R², freeze the **fixed 50-row historical-mean forecast sequence** as the one common denominator: `1 − Σ(actual−forecast)² / Σ(actual−fixed_mean)²`. Require a finite, strictly positive denominator. Keep each evaluation's local historical-mean-denominator metrics separately, as the validated `comparison_metrics` API does. Do not tune the model or choose among windows on the test period. Report raw negative HAR forecasts as such, together with their count; no post hoc clipping.

## Interpretation and release gate

Tier B's regular schedule is provisional: an individual dated CME exception could shift the true session grid and change RV, continuity, or both. Provider `AVAILABLE` metadata does not prove every empty minute is no-trade, nor does retained OHLCV reveal vendor correction timing. Causal roll selection depends on complete prior-session volume across candidate contracts; ambiguity can alter the selected series and the variance target. Pre-2012 trade-date mapping remains excluded. These uncertainties can create selection bias because only full-grid, cleaner sessions enter the sample; any apparent predictive skill would describe that conditional subset, not all NQ sessions.

**Current decision: NO-GO for the separately labeled exploratory fit and evaluation.** The largest current A/B run has 44 sessions versus the fixed 120-session gate, and only 22 possible target rows versus 98 required. A future GO requires a new, dated metadata manifest showing at least 120 truly uninterrupted A/B sessions, matched complete RV support, frozen source and code hashes, and the period assignment above **before** forecast inspection. That would permit an explicitly provisional exploratory run only; strict historical HAR remains subject to its existing independent certification gate.
